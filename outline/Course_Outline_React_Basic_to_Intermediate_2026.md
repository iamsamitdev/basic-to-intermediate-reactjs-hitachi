## เกี่ยวกับหลักสูตร

React.js ยังคงเป็นไลบรารีสำหรับพัฒนา Frontend ที่ได้รับความนิยมสูงสุดในปัจจุบัน และมีพัฒนาการต่อเนื่องจนถึง React 19 ที่นำแนวคิดใหม่ ๆ เข้ามาช่วยให้การพัฒนาง่ายและมีประสิทธิภาพยิ่งขึ้น หลักสูตรนี้ได้รับการปรับปรุงเนื้อหาให้ทันสมัยสำหรับปี 2026 โดยเปลี่ยนมาใช้เครื่องมือมาตรฐานยุคใหม่อย่าง Vite แทน Create React App ที่เลิกพัฒนาแล้ว และใช้ TypeScript ตั้งแต่วันแรกเพื่อให้ผู้เรียนเขียนโค้ดได้อย่างปลอดภัยและเป็นมืออาชีพ

ผู้เข้าอบรมจะได้เรียนรู้ตั้งแต่พื้นฐานของ React, JSX/TSX, Component, Props, State, Hooks ไปจนถึงหัวข้อระดับกลางที่จำเป็นต่อการทำงานจริง เช่น การจัดการ Routing ด้วย React Router v7, การทำฟอร์มด้วย React Hook Form + Zod, การจัดการ State ด้วย Zustand และ Redux Toolkit, การดึงข้อมูลจาก API ด้วย TanStack Query, การทำระบบ Authentication รวมถึงการปรับแต่งประสิทธิภาพและการนำขึ้น Production จริง โดยปิดท้ายด้วยการลงมือทำโปรเจกต์เพื่อบูรณาการความรู้ทั้งหมด

# รายละเอียดเนื้อหาการอบรม

## วันที่ 1: ปูพื้นฐาน React 19 + TypeScript + Vite

> ปรับพื้นฐานให้แน่น เริ่มต้นโปรเจกต์ด้วยเครื่องมือยุคใหม่ และเขียน TypeScript ตั้งแต่บรรทัดแรก

### Module 1.1 รู้จัก React ในยุคปี 2026

- React.js คืออะไร และทำไมยังครองตลาด Frontend
- ภาพรวม Ecosystem ของ React ปี 2026 (React 19, ทางเลือก Framework)
- ทำความเข้าใจ SPA, SSR และ React Server Components (ภาพรวม)
- Virtual DOM, Reconciliation และบทบาทของ React Compiler
- สำรวจเว็บไซต์ระดับโลกที่พัฒนาด้วย React

### Module 1.2 เตรียมเครื่องมือสำหรับนักพัฒนา

- ติดตั้ง Node.js LTS และการใช้งาน npm / pnpm
- ตั้งค่า VS Code + Extensions (ESLint, Prettier, React Snippets)
- ติดตั้ง React Developer Tools บน Google Chrome
- ทำไมจึงเลิกใช้ Create React App (CRA) แล้วหันมาใช้ Vite

### Module 1.3 สร้างโปรเจกต์แรกด้วย Vite + React + TypeScript

- สร้างโปรเจกต์ด้วยคำสั่ง `pnpm create vite`
- ทำความเข้าใจโครงสร้างโปรเจกต์ของ Vite
- ทำความรู้จักไฟล์ `tsconfig.json` และ `vite.config.ts`
- การรัน Dev Server และการทำงานของ Hot Module Replacement (HMR)
- ตั้งค่า ESLint และ Prettier ให้โปรเจกต์

### Module 1.4 TypeScript ที่จำเป็นสำหรับ React

- ทำไม TypeScript จึงกลายเป็นมาตรฐานของการพัฒนา React
- ความแตกต่างของ `type` และ `interface`
- ชนิดข้อมูลพื้นฐาน, Array, Object, Union และ Literal Types
- Function Types และ Generics เบื้องต้น
- Type Inference และการเขียนโค้ดในไฟล์ `.tsx`

### Module 1.5 JSX/TSX และ Component แรกของคุณ

- JSX / TSX คืออะไร และข้อกำหนดพื้นฐาน
- การแสดงค่าตัวแปรและการคำนวณ (Expression) ใน JSX
- การสร้าง Function Component ตัวแรก
- การ export / import Component ระหว่างไฟล์
- การใช้งาน React Fragment

## วันที่ 2: Component, Props, State, Event และการจัดสไตล์

> เข้าใจหัวใจของ React คือการประกอบ Component พร้อมจัดการข้อมูลด้วย Props/State และตกแต่งหน้าตาด้วย Tailwind CSS v4

### Module 2.1 React Component เชิงลึก

- เน้น Function Component (แนวทางมาตรฐานยุคใหม่ ไม่ใช้ Class)
- หลักการออกแบบ Component ให้นำกลับมาใช้ซ้ำ (Reusable)
- Component Composition และการใช้งาน `children`
- แนวทางการจัดโครงสร้างโฟลเดอร์ของ Component

### Module 2.2 การทำงานกับ Props ด้วย TypeScript

- รู้จัก Props ใน React
- การกำหนด Type ให้กับ Props ด้วย `interface` / `type`
- การกำหนดค่าเริ่มต้น (Default Props)
- การกำหนด Type ให้กับ `children` (`React.ReactNode`)
- การส่งค่าหลายค่าและการใช้ Spread Props
- การส่งฟังก์ชัน (Callback) ผ่าน Props

### Module 2.3 การจัดการ State ด้วย useState

- รู้จัก State และความสำคัญในการ Render
- การใช้งาน `useState` ร่วมกับ TypeScript
- การอัปเดต State อย่างถูกต้องตามหลัก Immutability
- การจัดการ State ที่เป็น Object และ Array
- การยก State ขึ้นไปไว้ Component แม่ (Lifting State Up)

### Module 2.4 การจัดการ Event

- การจัดการ Event ต่าง ๆ ใน React
- การกำหนด Type ให้ Event (`ChangeEvent`, `MouseEvent` ฯลฯ)
- ทำความเข้าใจ Synthetic Events
- การส่ง Argument เข้าไปใน Event Handler

### Module 2.5 Conditional Rendering และการแสดงผลรายการ (List)

- การแสดงหรือซ่อนเนื้อหา (`if`, `&&`, ternary operator)
- การแสดงผลรายการด้วย `map()`
- ความสำคัญและการกำหนด `key` ที่ถูกต้อง
- การ filter และ sort ข้อมูลก่อนแสดงผล

### Module 2.6 การจัดสไตล์ด้วย Tailwind CSS v4

- ภาพรวมแนวทางการจัดสไตล์ใน React (Inline, CSS Modules, Tailwind)
- การติดตั้ง Tailwind CSS v4 ร่วมกับ Vite
- แนวคิด Utility-First และการใช้ Utility Classes
- การทำ Responsive, Hover State และ Dark Mode
- ตัวอย่างการตกแต่ง Component ให้สวยงามด้วย Tailwind

## วันที่ 3: React Hooks เชิงลึก, Side Effects และฟีเจอร์ใหม่ของ React 19

> เจาะลึก Hooks สำคัญ การจัดการ Side Effects การสร้าง Custom Hooks และฟีเจอร์ใหม่ล่าสุดของ React 19

### Module 3.1 useEffect และการจัดการ Side Effects

- Side Effects คืออะไร
- การใช้งาน `useEffect` และ Dependency Array
- การเขียน Cleanup Function
- รูปแบบการเรียก API ด้วย `useEffect` และข้อจำกัด
- ข้อผิดพลาดที่พบบ่อย เช่น Infinite Loop

### Module 3.2 Hooks สำคัญอื่น ๆ

- `useRef` สำหรับเข้าถึง DOM และเก็บค่าโดยไม่ Re-render
- `useMemo` สำหรับ Memoize ค่าที่คำนวณ
- `useCallback` สำหรับ Memoize ฟังก์ชัน
- เมื่อไรควรและไม่ควรใช้ และ React Compiler ช่วยได้อย่างไร

### Module 3.3 Context API

- ปัญหา Prop Drilling
- การใช้งาน `createContext`, `Provider` และ `useContext`
- การกำหนด Type ให้กับ Context
- ตัวอย่างการทำ Theme Context และ Auth Context

### Module 3.4 การสร้าง Custom Hooks

- ทำไมจึงต้องใช้ Custom Hooks
- การสร้าง Custom Hook (`useToggle`, `useFetch`, `useLocalStorage`)
- กฎการใช้งาน Hooks (Rules of Hooks)
- การนำ Logic กลับมาใช้ซ้ำ (Reuse Logic)

### Module 3.5 ฟีเจอร์ใหม่ของ React 19

- ภาพรวมสิ่งใหม่ที่เพิ่มเข้ามาใน React 19
- `use()` Hook สำหรับอ่านค่า Promise และ Context
- Actions และ Form Actions
- `useActionState` สำหรับจัดการสถานะของ Action
- `useOptimistic` สำหรับทำ Optimistic UI
- `useFormStatus` สำหรับติดตามสถานะฟอร์ม
- `ref` เป็น prop ได้โดยตรง (เลิกใช้ `forwardRef`)
- ทำความรู้จัก React Compiler และประโยชน์ที่ได้รับ

## วันที่ 4: Routing, ฟอร์มมืออาชีพ และ State Management

> สร้างแอปหลายหน้าด้วย React Router v7 จัดการฟอร์มอย่างมืออาชีพด้วย React Hook Form + Zod และเปรียบเทียบเครื่องมือ State Management ยอดนิยม

### Module 4.1 React Router v7

- การติดตั้งและภาพรวมของ React Router v7
- การกำหนดเส้นทาง (Routes)
- การใช้งาน `Link`, `NavLink` และการแสดงสถานะ Active
- Nested Routes และ Layout Routes
- การรับค่าพารามิเตอร์แบบ Dynamic (`useParams`)
- การจัดการ Query String (`useSearchParams`)
- การเปลี่ยนหน้าด้วยโค้ด (`useNavigate`)
- การทำ Protected Routes (Auth Guard)
- การจัดการหน้า 404 และหน้าแสดงข้อผิดพลาด
- การใช้งาน Loader และ Data API เบื้องต้น

### Module 4.2 ฟอร์มระดับมืออาชีพด้วย React Hook Form + Zod

- ทบทวน Controlled vs Uncontrolled Components
- การติดตั้งและใช้งาน React Hook Form
- การใช้งาน `register`, `handleSubmit` และ `formState`
- การ Validate ข้อมูลด้วย Zod + `zodResolver`
- การจัดการและแสดงข้อความ Error
- ตัวอย่าง: ฟอร์ม Login และ Register แบบสมบูรณ์

### Module 4.3 State Management: เมื่อ useState ไม่เพียงพอ

- ทบทวนความซับซ้อนในการจัดการ State
- เมื่อไรควรใช้ Global State Management

### Module 4.4 Zustand (Global State แบบเบาและยืดหยุ่น)

- การติดตั้งและสร้าง Store
- การเรียกใช้งาน Store ภายใน Component
- การอัปเดต State และการสร้าง Action
- การใช้ Middleware (`persist`, `devtools`)
- การกำหนด Type ให้กับ Store

### Module 4.5 Redux Toolkit (State Management ระดับองค์กร)

- ทำความเข้าใจ Redux Flow และ Redux Toolkit
- การใช้งาน `configureStore` และ `createSlice`
- การ dispatch และ select ข้อมูล (`useSelector`, `useDispatch`)
- การจัดการ Asynchronous ด้วย `createAsyncThunk`
- การใช้งาน Redux DevTools
- RTK Query เบื้องต้น
- เปรียบเทียบ Zustand กับ Redux Toolkit และการเลือกใช้

## วันที่ 5: Data Fetching, Authentication, Performance, Deploy และ Workshop

### Module 5.1 Data Fetching ด้วย TanStack Query (React Query v5)

- ปัญหาของการ Fetch ข้อมูลด้วย `useEffect`
- รู้จัก TanStack Query และแนวคิด Server State
- การใช้งาน `useQuery` (Fetching, Caching, Stale Time)
